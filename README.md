# AgroLens

ПР5 · КНШІ-11 · 2026
Кишеньковий агроном зі штучним інтелектом: діагностика хвороб рослин за фото,
побутовий режим догляду, офлайн-довідник, погодні ризики та AI-агроном.

## Швидкий старт

1. Відкрийте `start.bat` (запускає локальний сервер на `http://localhost:8080`).
2. Або просто відкрийте `index.html` у браузері — застосунок працює і з `file://`.
3. Перший запуск показує коротке знайомство. Демо-режим уже активний.

## Режими

- **Ферма** (основний): поля, гектари, стадії культур, ризик хвороб, вікно обробки.
- **Дім** (безкоштовний і повний): кімнатні та балконні рослини, полив, нагадування,
  симптом-чекер, журнал, довідник, чат.

Перемикач режимів — у бічній панелі або в налаштуваннях.

## AI

- Без ключа працює **демо-режим**: локальна база з 16 хвороб, симптом-чекер,
  демо-діагностика фото та локальний агроном.
- Реальний аналіз вмикається ключем **Google AI Studio (Gemini)**:
  `Налаштування → AI-діагностика → Отримати безкоштовно`.
- Ключ зберігається лише в `localStorage` браузера. Модель за замовчуванням —
  `gemini-2.5-flash`, є фолбек на `gemini-2.0-flash`.
- Якщо Gemini недоступний, застосунок автоматично повертається до демо-відповіді.

## Сценарій ПР5

Фермер або власник кімнатних рослин хоче сфотографувати уражений листок і за секунди
отримати діагноз із планом лікування, щоб урятувати врожай чи улюблену рослину без
консультації агронома.

## Дані

Усе зберігається локально в `localStorage` під ключем `agrolens.v3`.
Експорт JSON — у журналі або налаштуваннях. Скидання — там само.

## Звіт ПР5

- `docs/report/AgroLens_PR5_Zvit.docx` — звіт (14 сторінок, 13 рисунків, 5 таблиць).
- `docs/report/AgroLens_PR5_Zvit.pdf` — той самий звіт для перегляду.
- `docs/make_report.py` — генератор звіту: `python docs/make_report.py`.
  Скріншоти беруться з `docs/shots/`, готові зображення — з `docs/report/img/`.

## Перевірка

- `node docs/verify.mjs` — симптом-чекер (T6) і офлайн-режим через CDP.
- `node docs/capture.mjs` — скріншоти для звіту (Chrome з `--remote-debugging-port=9222`).
- `node docs/reshoot.mjs` — повторні знімки окремих екранів на вищих вьюпортах.
